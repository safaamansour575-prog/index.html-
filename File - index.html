لغة جافا سكريبت (JavaScript)

عمل الطالبة: صفاء منصور موسى عبد الحق

الرقم الجامعي: 2501341

أولاً: المقدمة

أصبحت مواقع الويب في الوقت الحالي جزءًا أساسيًا من حياتنا اليومية، حيث نستخدمها في التعليم والتواصل والتسوق والعمل والترفيه. ومع تطور شبكة الإنترنت، لم تعد صفحات الويب مجرد صفحات تحتوي على نصوص وصور ثابتة، بل أصبحت صفحات تفاعلية تستطيع الاستجابة لأفعال المستخدم وتنفيذ أوامر مختلفة بمجرد النقر أو الكتابة أو تحريك مؤشر الفأرة. وتعد لغة JavaScript من أهم التقنيات التي ساهمت في هذا التطور؛ فهي لغة برمجة تستخدم لإضافة التفاعل والحركة والوظائف المختلفة إلى صفحات الويب.

ثانياً: عرض الموضوع

1- ما هي لغة JavaScript؟

JavaScript هي لغة برمجة ت​ستخدم بشكل أساسي لإضافة التفاعل والوظائف الديناميكية إلى صفحات الويب. وهي تعمل إلى جانب لغات وتقنيات أخرى، أهمها هيكل الصفحة الذي يتم إنشاؤه بواسطة HTML، وشكل ومظهر الصفحة المعتمد على CSS، بينما تعطي JavaScript الحركة والتفاعل والسلوك.

2- كيف تجعل JavaScript صفحات الويب تفاعلية؟

تعتمد لغة جافا سكريبت على فكرة أساسية وهي الاستجابة لـ الأحداث (Events). والحدث هو أي إجراء يقوم به المستخدم أو يحدث داخل صفحة الويب مثل النقر على زر، كتابة نص داخل مربع، أو تحريك مؤشر الفأرة.

3- أهمية ومميزات لغة JavaScript

تتمتع لغة JavaScript بأهمية كبيرة جداً في تطوير الويب لأنها تسمح بالاستجابة لنقرات المستخدم وتغيير محتوى الصفحة دون الحاجة لإعادة تحميلها بالكامل، بالإضافة إلى التحقق من البيانات داخل النماذج لتقليل الأخطاء.

مقارنة بين الصفحة الثابتة والصفحة التفاعلية

نوع الصفحة الخصائص وأسلوب العمل
الصفحة الثابتة تعرض المحتوى للمستخدم (عنوان + صورة + نص)، ولكنها لا تتغير كثيرًا بناءً على تصرفاته ولا توجد استجابة كبيرة لأفعاله.
الصفحة التفاعلية تستجيب لتصرفات المستخدم مباشرة؛ فعندما يضغط على زر تظهر نافذة أو يتغير النص والألوان دون إعادة تحميل الموقع.

الخاتمة

في النهاية، يمكن القول إن لغة جافا سكريبت لعبت دورًا أساسيًا في تطور صفحات الويب وتحويلها من صفحات ثابتة تعرض المعلومات فقط إلى صفحات تفاعلية قادرة على الاستجابة للمستخدم وتلبية احتياجاته.
